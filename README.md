# Marina Madžgalj – Portfolio

Personal portfolio website showcasing my projects, skills and background as a Software Developer.

This site is built as a clean, single-page portfolio with a focus on simple UX, responsive layout and easily maintainable code.

---

## 🔗 Live Demo
**Live site:** https://marinascepanovic.github.io/Portfolio/

---

## ✨ Features
- Single-page layout with smooth navigation (top navbar + floating bottom nav)
- Responsive design for desktop, tablet and mobile
  - Resume section with tabbed content:
  - Experience (key projects)
  - Education
  - Skills
  - About me
- Featured projects with live demo links and GitHub repositories
- Project filtering (All / Frontend / Backend)
- Light / Dark theme toggle (stored in localStorage)
- Subtle scroll animations using AOS (Animate On Scroll)
- Clean, modern typography (Google Fonts – Montserrat)
- Contact section with a working contact form powered by FormSubmit

---

## 🛠 Tech Stack

**Core:**

- HTML5
- CSS3 (custom, no CSS frameworks)
- Vanilla JavaScript (ES6+)


**Tools & Libraries:**

- [AOS](https://michalsnik.github.io/aos/) – scroll animations
- [Unicons](https://iconscout.com/unicons)  – icon set
- [Google Fonts](https://fonts.google.com/) – Montserrat
- [FormSubmit](https://formsubmit.co/) – form handling (no backend required)
